# gynaicologos.gr — νέο website

Στατικό website (HTML/CSS/JS, χωρίς build dependencies) για τον
**Ρώτα Μιχάλη MD, FACOG** — Μαιευτήρα Χειρουργό Γυναικολόγο, Ειδικό Εμβρυομητρικής Ιατρικής.

Το περιεχόμενο έχει αντληθεί εξ ολοκλήρου από το υπάρχον WordPress site
(`https://gynaicologos.gr`) μέσω του WP REST API και αναδομήθηκε σε καθαρό,
σημασιολογικό HTML.

## Δομή

Σύνολο: **118 σελίδες** (1 αρχική + 1 επικοινωνία + 6 ενότητες + 110 σελίδες περιεχομένου).

### Υπογονιμότητα — δομή (Αύγουστος 2026)

Η ενότητα αναδομήθηκε σε **τρία μεγάλα sub-dropbars**, σύμφωνα με το κείμενο του
ιατρού (`rotas allages 3.txt`):

1. **Διερεύνηση Υπογονιμότητας** → Διερεύνηση γυναίκας (ορμονικός έλεγχος,
   σαλπιγγογραφία/HyCoSy, υποδεκτικότητα ενδομητρίου, χρόνια ενδομητρίτιδα) ·
   Διερεύνηση του άνδρα (ορμονικός έλεγχος, σπερμοδιάγραμμα, ειδικές εξετάσεις σπέρματος)
2. **Θεραπείες Υπογονιμότητας** → πρόκληση ωοθυλακιορρηξίας, IUI, εξωσωματική,
   φυσικός κύκλος, δότρια ωαρίου, δότης σπέρματος, κατάψυξη ωαρίων
3. **Νεότερες τεχνολογίες** → time-lapse (EmbryoScope+), υποβοηθούμενη εκκόλαψη, PGT

Τα κείμενα βρίσκονται στο `_build/extra_content.py` (όχι στο `content.json`, που
είναι το παλιό WordPress scrape). Επτά παλιές σελίδες μένουν ζωντανές εκτός μενού
(`"extra"` στο `structure.py`) και εμφανίζονται στο τέλος της σελίδας ενότητας,
ώστε να μη σπάσουν παλιά URLs.

## Γύρος διορθώσεων — Σεπτέμβριος 2026

Αίτημα του ιατρού, όλα περνάνε από τον generator:

- Τίτλος hero σε μία σειρά και αρκετά μικρότερος (`.home .hero--photo .hero-title`,
  `white-space: nowrap` με μέγεθος σε `vw`).
- Όλοι οι τίτλοι της αρχικής με κεφαλαία και στο ίδιο μέγεθος. Το `<body>` της
  αρχικής παίρνει `class="home"` (`shell(..., body_class="home")`) ώστε οι
  εσωτερικές σελίδες να μένουν όπως ήταν.
- Slider: η 4η καρτέλα «Αναπαραγωγή» → «Εξωσωματική».
- Νέο bullet στα προσόντα (`HOME_CREDS`): συνεργάτης της Μονάδας Υποβοηθούμενης
  Αναπαραγωγής του Μαιευτηρίου ΡΕΑ.
- «Καλλιέργεια κολπικού υγρού»: από τα «Γυναικολογικά θέματα» στο τέλος της
  «Γυναικολογικής εξέτασης» (`structure.py`).
- Σελίδα «Δημοσιεύσεις»: ξαναχτίστηκε σαν το παλιό site — μία κάρτα ανά
  δημοσίευση με το εξώφυλλο του περιοδικού (`PUBLICATIONS` στο `build.py`,
  εικόνες στο `assets/journals/`).

- Βιογραφικό: η δεύτερη φωτογραφία του ιατρού (πορτρέτο μπροστά στους τίτλους,
  σχεδόν ίδια με την πρώτη) αντικαταστάθηκε από το `assets/bio/dr-rotas-embryocosmos-portrait.jpg`.
- `article-images.js`: οι εικόνες έμπαιναν μόνο στις ελληνικές σελίδες. Τώρα η
  αντιστοίχιση γίνεται μέσω του `link[rel=alternate][hreflang="el"]` κάθε
  αγγλικής σελίδας, το `assets/` υπολογίζεται από το src του ίδιου του script
  (όχι από hardcoded ονόματα φακέλων) και η λεζάντα στα αγγλικά παίρνει τον
  τίτλο της σελίδας. Η ορφανή `en/pregnancy/breastfeeding.html` του παλιού
  αγγλικού site έγινε redirect στην `postpartum-and-breastfeeding.html`.

Το `strip_dashes()` κόβει τα « — » από τις παραγόμενες σελίδες, οπότε τα κλειδιά
του `_build/i18n/strings/` που έχουν παύλα δεν ταίριαζαν πια· το
`strings/__init__.py` καταχωρεί πλέον αυτόματα και την εκδοχή χωρίς παύλα.

## Design

Ίδια σχεδιαστική γλώσσα με το `dental-harmony-website` (Cormorant Garamond + Jost,
reveal-on-scroll, sticky header, mega-menu).

**Παλέτα:** χτισμένη πάνω στο χρώμα του logo. Δειγματοληψία του `assets/logo.png`
έδωσε `#c04eb4` (hue 307°) — όλες οι αποχρώσεις κάθονται στον ίδιο άξονα 305–315°:

| Μεταβλητή | Hex | Χρήση |
| --- | --- | --- |
| `--cream` | `#fdf9fc` | φόντο σελίδας |
| `--sand` | `#f9edf7` | εναλλασσόμενα sections |
| `--blush` | `#f2d4ec` | ροζ highlights |
| `--rose` | `#c04eb4` | **χρώμα logo** — accent, διακόσμηση |
| `--rose-ink` | `#9c3b8f` | μικρά κείμενα (AA) |
| `--mocha` | `#8a5a83` | eyebrows / meta |
| `--cocoa` | `#5e3557` | τίτλοι, φόντο footer |
| `--ink` | `#402b3d` | κυρίως κείμενο |

Όλοι οι συνδυασμοί περνούν **WCAG AA**: κυρίως κείμενο 12.3:1, δευτερεύον 6.7:1,
τίτλοι 9.5:1, λευκό σε ροζ κουμπί 4.7:1.

## Ξαναχτίσιμο

Οι σελίδες παράγονται από τον generator στο `_build/`:

```bash
python3 _build/build.py
```

- `_build/content.json` — το περιεχόμενο όπως αντλήθηκε από το WordPress
- `_build/structure.py` — ο χάρτης του site (ενότητες, slugs, τίτλοι, στοιχεία ιατρείων)
- `_build/build.py` — ο generator

Για αλλαγή σε στοιχεία επικοινωνίας, τίτλους ή δομή μενού, επεξεργαστείτε το
`structure.py` και τρέξτε ξανά τον generator. Ο φάκελος `_build/` **δεν** χρειάζεται
να ανέβει στον server.

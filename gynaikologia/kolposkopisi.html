Κολποσκόπηση

Η κολποσκόπηση είναι ένας τύπος εξέτασης του τραχήλου της μήτρας κατά την οποία χρησιμοποιείται μια ειδική μεγεθυντική συσκευή, που ονομάζεται κολποσκόπιο και ρίχνει φως…

Τι είναι η κολποσκόπηση;

Η κολποσκόπηση είναι ένας τύπος εξέτασης του τραχήλου της μήτρας κατά την οποία χρησιμοποιείται μια ειδική μεγεθυντική συσκευή, που ονομάζεται κολποσκόπιο και ρίχνει φως στον κόλπο και τον τράχηλο της μήτρας. Ένα κολποσκόπιο μπορεί να μεγεθύνει σημαντικά την κανονική όψη των οργάνων της γυναίκας. Αυτή η εξέταση επιτρέπει στον γυναικολόγο να εντοπίσει προβλήματα τα οποία δεν είναι ορατά με γυμνό μάτι.

Γιατί γίνεται η κολποσκόπηση;

Η κολποσκόπηση γίνεται όταν τα αποτελέσματα του τεστ Παπανικολάου δείχνουν μη φυσιολογικές αλλαγές στα κύτταρα του τραχήλου της μήτρας. Η κολποσκόπηση παρέχει περισσότερες πληροφορίες σχετικά με τα παθολογικά κύτταρα. Η κολποσκόπηση μπορεί επίσης να χρησιμοποιηθεί για την περαιτέρω αξιολόγηση άλλων προβλημάτων, όπως τα παρακάτω:

  • Κονδυλώματα των γεννητικών οργάνων στον τράχηλο
  • Τραχηλίτιδα (φλεγμονή του τραχήλου της μήτρας)
  • Καλοήθεις (όχι καρκινικές) αναπτύξεις, όπως πολύποδες
  • Πόνος
  • Αιμορραγία

Μερικές φορές η κολποσκόπηση μπορεί να χρειαστεί να γίνει περισσότερες από μία φορές. Μπορεί επίσης να χρησιμοποιηθεί για τον έλεγχο του αποτελέσματος μιας θεραπείας.

Ποια είναι η διαδικασία της κολποσκόπησης;

Η κολποσκόπηση γίνεται όπως το τεστ Παπ στο γυναικολογικό ιατρείο. Ωστόσο, είναι πιθανό να χρειαστεί να παραπεμφθείτε σε άλλον ιατρό ή σε ειδική κλινική για να την κάνετε. Η διαδικασία γίνεται καλύτερα όταν μια γυναίκα δεν έχει έμμηνο ρύση, διότι τότε ο γιατρός έχει μια καλύτερη εικόνα του τραχήλου της μήτρας. Για τουλάχιστον 24 ώρες πριν από την εξέταση δεν πρέπει:

  • Να έχετε κάνει ντους
  • Να χρησιμοποιείτε ταμπόν
  • Να χρησιμοποιείτε κολπικά φάρμακα
  • Να έχετε σεξουαλικές επαφές

Όπως συμβαίνει σε μια τυπική γυναικολογική εξέταση, έτσι και στην κολποσκόπηση θα χρειαστεί να ξαπλώσετε ανάσκελα με τα πόδια σας σηκωμένα και τοποθετημένα στις ειδικές βάσεις για στήριξη. Θα χρησιμοποιηθεί ένας κολποδιαστολέας για να συγκρατήσει τα τοιχώματα του κόλπου έτσι ώστε να είναι ορατό το εσωτερικό του κόλπου και του τραχήλου της μήτρας. Το κολποσκόπιο τοποθετείται ακριβώς έξω από το άνοιγμα του κόλπου σας. Ένα ήπιο διάλυμα θα εφαρμοστεί στον τράχηλο και τον κόλπο σας με έναν στυλεό ή βαμβάκι. Αυτό το υγρό καθιστά ευκολότερες τις ανώμαλες περιοχές στον τράχηλο της μήτρας. Είναι πιθανό να αισθανθείτε ένα ελαφρύ κάψιμο.

Πότε πραγματοποιείται βιοψία κατά την κολποσκόπηση;

Κατά τη διάρκεια της κολποσκόπησης είναι πιθανό ο γυναικολόγος να παρατηρήσει κάποιες μη φυσιολογικές περιοχές. Μπορεί να γίνει βιοψία αυτών των περιοχών. Κατά τη διάρκεια μιας βιοψίας, ένα μικρό κομμάτι μη φυσιολογικού ιστού αφαιρείται με ειδική συσκευή από τον τράχηλο. Τα κύτταρα μπορούν επίσης να ληφθούν από τον ενδοτραχηλικό σωλήνα, με χρήση ειδικής συσκευής για τη συλλογή των κυττάρων. Η διαδικασία αυτή ονομάζεται ενδοτραχηλική απόξεση (ECC).

Τι πρέπει να περιμένω κατά τη διάρκεια της ανάρρωσης;

Εάν κάνετε κολποσκόπηση χωρίς λήψη βιοψίας, θα πρέπει να αισθάνεστε καλά αμέσως και μπορείτε να κάνετε τα πράγματα που κάνετε συνήθως. Μπορεί να έχετε λίγες κηλίδες αίματος για μερικές μέρες. Εάν κάνετε κολποσκόπηση με βιοψία, ο κόλπος σας μπορεί να πονάει για 1 ή 2 ημέρες. Μπορεί να έχετε κάποια κολπική αιμορραγία. Μπορεί επίσης να έχετε σκούρες εκκρίσεις για μερικές ημέρες. Αυτό μπορεί να οφείλεται στη φαρμακευτική αγωγή που χρησιμοποιείται για να σταματήσει η αιμορραγία στο σημείο από το οποίο έχει ληφθεί η βιοψία. Είναι πιθανό να χρειαστεί να φοράτε σερβιέτα μέχρι να σταματήσει η έκκριση. Ο γιατρός σας μπορεί να σας προτείνει να περιορίσετε τη δραστηριότητά σας για ένα σύντομο χρονικό διάστημα. Ενώ ο τράχηλος θεραπεύεται, θα σας πει να μην βάζετε τίποτα στον κόλπο σας για σύντομο χρονικό διάστημα:

  • Μην έρχεστε σε σεξουαλική επαφή.
  • Μη χρησιμοποιείτε ταμπόν.
  • Μην κάνετε κολπικά ντους.

Καλέστε αμέσως τον γυναικολόγο σας εάν έχετε οποιοδήποτε από τα παρακάτω προβλήματα:

  • Βαριά κολπική αιμορραγία (χρησιμοποιώντας περισσότερες από μία σερβιέτες ανά ώρα)
  • Έντονο πόνος στην κάτω κοιλιακή χώρα
  • Πυρετό
  • Ρίγη
